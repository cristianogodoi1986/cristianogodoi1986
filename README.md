## 🚀 Projetos em destaque

### 🏖️ SIGAF — Sistema de Gestão de Afastamentos e Férias
Dashboard interativo em **HTML puro + JavaScript** para controle de férias, afastamentos e pendências de equipes técnicas.  
Importa planilhas Excel, gera calendário, matriz de cobertura, KPIs e exportação — tudo rodando no navegador, sem servidor.

- Calendário diário + matriz colaborador × dia
- KPIs (Gades, Capital/Interior, % afastados)
- Filtros, pendentes com prazo e backup local
- Tecnologias: HTML5, CSS3, JavaScript, SheetJS

> Repositório principal (privado para uso operacional). Versão pública de referência disponível nos pins do perfil.
